# 🤝 Contributing to SynaptoBot AI

Thank you for your interest in contributing to **SynaptoBot AI**! Because this repository focuses on public architecture documentation, executive briefs, and ecosystem telemetry standards, please review our guidelines below before participating.

---

## 📋 Guidelines for Collaboration

1. **Documentation & Architecture:** Contributions aimed at improving architectural diagrams, markdown guides, or integration documentation are welcome via Pull Requests.
2. **Security First (The Kryptonite Rule):** No contributions involving proprietary MQL5 execution algorithms, private keys, or sensitive environment configurations will be accepted, as core trading logic remains strictly isolated.
3. **Reporting Issues:** If you find typos, broken links, or clarity issues in the public documentation, please open an **Issue** on GitHub or reach out directly through our official [Discord Server](https://discord.gg/synaptobotai).
